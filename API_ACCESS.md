# API access options (updated 13 October 2026)

**Fastest self-service route:** Public AI lists Apertus 1.5 8B and 70B and $2 starter credits for a newly created account: https://platform.publicai.co/docs. See `PUBLICAI_QUICKSTART.md`.

**Competition's CSCS allocation:** the official resources page currently marks "CSCS - Inference for all teams - closed now": https://hackapertus.devpost.com/resources. Hack Apertus Discord is https://discord.gg/hack-apertus; the final deadline is 16 October 2026 12:00 CEST. Do not rely on late access.

**Swiss AI academic research guest access:** https://serving.swissai.svc.cscs.ch/faq explicitly allows access requests for Apertus-focused work from non-Swiss universities by email to swissaiserving@ai.ethz.ch. Guest access is manual, not guaranteed.

**Standard CSCS API:** https://api.inference.cscs.ch/v1 ; CSCS normally requires project membership, an inference resource and a key: https://docs.cscs.ch/services/inference/api/.

Public AI is internationally hosted and its experiment is NOT equivalent to Swiss-sovereign inference; describe Swiss hosting only as a supported future deployment option. The runner uses a provider-specific model alias and verifies returned model identifiers, not just submitted names. Never share credentials.
